## Independent security review

A separate read-only reviewer inspected `b3627e06a28eee5308595f939fc3d0af700fe4d7` then rechecked the exact corrected candidate above. The final independent strict run passed 64 tests with no skips. The review covered authority, staged bytes and descriptor inheritance, sandbox isolation, shutdown, and evidence scope.

| Finding | Resolution |
| --- | --- |
| Medium · Hashing and copying dependencies under the SQLite writer transaction could delay cancellation. | Stage outside the writer lock, check cancellation and elapsed budget, and recheck the grant, lease and source at launch. Regression exercises cancellation while staging is paused. |
| Medium · A hard stop could leave up to 2 GiB of staged runtime on disk. | Use a private managed staging root and reclaim known staging entries on the next pilot dispatch after obtaining the supervisor-held lock. The temporary on-disk retention after a hard stop is documented. |
| Low · The traversal limit counted only regular files. | Count directories and files and retain bounded depth, size and elapsed time. |
| Provenance and portability | Document how the operator authenticates the local Git export, constrain the unchanged-source claim to scoped files and HEAD, and check actual Bubblewrap flags. |

No independent review blockers remain. Ubuntu 22.04 and the operator's physical workstation have not been verified. See the [operator guide](README.md) for setup and NX-006.
